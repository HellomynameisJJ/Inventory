# Inventario J&J

Web-based system for **inventory, sales, and customer debt control**.

This project is built using **HTML, CSS, and JavaScript**, storing data locally with **LocalStorage** (no backend required).

---

## 🚀 Features

- 🔐 Login system
- 📦 Inventory management (entries & exits)
- 💰 Sales and returns tracking
- 👥 Customer & debt control
- 📊 Charts with Chart.js
- 💾 Persistent data using LocalStorage
- 📱 Responsive design (mobile-friendly)

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Chart.js
- LocalStorage API
